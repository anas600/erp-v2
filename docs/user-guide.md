# دليل المستخدم — ERP-V2

> هذا الدليل مخصص لمستخدم النظام (المحاسب، مدير الشركة، المهندس). للغات النشر والصيانة، راجع `deployment.md` و `../README.md`.

## 1. تسجيل الدخول

1. افتح المتصفح على عنوان النظام (مثلاً `http://localhost:3000` أو عنوان الـ VPS).
2. أدخل البريد الإلكتروني وكلمة المرور.
3. اضغط **دخول**.

**الحسابات التجريبية** (تتغير في الإنتاج):

| المستخدم | كلمة المرور | الدور |
|---------|------------|------|
| `admin@holding.ly` | `admin123` | مدير عام (كل الصلاحيات) |
| `accountant@company-a.ly` | `acc123` | محاسب (شركة ألف وباء) |
| `engineer@company-a.ly` | `eng123` | مهندس مشاريع (شركة ألف فقط) |

## 2. الواجهة الرئيسية

- **الشريط الجانبي** على اليمين يحوي القائمة: الرئيسية، الشركات، شجرة الحسابات، القيود اليومية، قواعد العمل، ميزان المراجعة.
- **شريط الشركة** في الأعلى يعرض الشركة الحالية. اضغط عليه للتبديل بين شركاتك.
- **قائمة المستخدم** على اليسار فيها الخروج.

## 3. تبديل الشركة

1. اضغط على اسم الشركة في الشريط العلوي.
2. اختر الشركة المرغوبة من القائمة المنسدلة.
3. النظام يولّد رمزاً جديداً (Token) ويحمّل بيانات الشركة المختارة.

> ملاحظة: تشاهد فقط الشركات التي تم ربطك بها. مدير الشركة القابضة يقدر يرى كل الشركات.

## 4. لوحة التحكم (الرئيسية)

تعرض:
- إجمالي الأصول
- إجمالي الخصوم
- حقوق الملكية
- صافي الدخل
- ملخص مالي (إيرادات / مصروفات)
- ميزان المراجعة (متوازن أو غير متوازن)

## 5. إدارة الشركات (للمدير العام فقط)

1. اذهب إلى **الشركات** من القائمة.
2. اضغط **شركة جديدة**.
3. أدخل:
   - **الكود** (مثلاً `CO-C`).
   - **الاسم بالإنجليزية** و **الاسم بالعربية**.
   - **الشركة الأم** (اختر الشركة القابضة).
4. اضغط **حفظ**.

## 6. شجرة الحسابات

1. اذهب إلى **شجرة الحسابات**.
2. تشاهد الحسابات الحالية (الأصول 1xxx، الخصوم 2xxx، إلخ).
3. لإضافة حساب جديد: اضغط **حساب جديد** وأدخل:
   - **الكود** (مثلاً `1100-01` لحساب فرعي تحت "البنك").
   - **الاسم بالإنجليزية والعربية**.
   - **النوع**: أصول / خصوم / حقوق ملكية / إيرادات / مصروفات.
   - **الطبيعة**: مدين / دائن.
4. اضغط **حفظ**.

> 💡 **قاعدة الطبيعة**: الحساب من نوع أصول أو مصروفات → طبيعته مدين افتراضياً. الحساب من نوع خصوم أو إيرادات أو حقوق ملكية → طبيعته دائن. الحسابات المعكوسة (مثل مجمع الإهلاك) تُعكس طبيعتها يدوياً.

## 7. إنشاء قيد يومية

1. اذهب إلى **القيود اليومية**.
2. اضغط **قيد جديد**.
3. أدخل:
   - **التاريخ**.
   - **البيان** (مثلاً "دفع إيجار شهر أغسطس").
4. لكل بند في القيد:
   - اختر **الحساب** من القائمة.
   - أدخل المبلغ في عمود **مدين** أو **دائن** (ليس الاثنين معاً).
   - اختياري: **بيان البند**.
5. اضغط **+ بند جديد** لإضافة بنود أكثر.
6. النظام يعرض **إجمالي المدين** و **إجمالي الدائن** وحالة التوازن.
7. اضغط **حفظ كمسودة** لإنشاء القيد.

## 8. ترحيل قيد

1. في قائمة القيود، ابحث عن القيد بحالة **مسودة**.
2. اضغط **ترحيل** على نفس الصف.
3. النظام:
   - يتحقق من توازن القيد.
   - يحدّث أرصدة الحسابات المعنية.
   - يحوّل الحالة إلى **مرحّل**.

> ⚠️ لا يمكن تعديل قيد مرحّل. لعكس قيد، استخدم **عكس** (متاح في الإصدارات اللاحقة).

## 9. محرك قواعد العمل

### 9.1. عرض القواعد الجاهزة

1. اذهب إلى **قواعد العمل**.
2. تشاهد 6 قوالب جاهزة:
   - ترحيل فاتورة مشتريات
   - ترحيل فاتورة مبيعات
   - دفع مورد
   - تحصيل عميل
   - إهلاك شهري
   - إيراد مشروع (مرحلة مشروع)

### 9.2. تشغيل قاعدة (اختبار)

1. اضغط أيقونة ▶️ (تشغيل) بجانب القاعدة.
2. في نافذة الاختبار، أدخل بيانات تجريبية بصيغة JSON.
3. اضغط **تشغيل الاختبار**.
4. النظام يعرض القيد الناتج أو رسالة الخطأ.

**مثال لاختبار "ترحيل فاتورة مشتريات"**:
```json
{
  "invoice": { "number": "INV-001", "total": 1000, "tax": 0 },
  "supplier": { "name": "مورد تجريبي" }
}
```

### 9.3. تعديل قاعدة

1. اضغط أيقونة ✏️ (تعديل).
2. عدّل JSON في حقل "تعريف القاعدة".
3. اضغط **حفظ**.

### 9.4. إنشاء قاعدة جديدة

1. اضغط **قاعدة جديدة**.
2. اختر:
   - **اسم القاعدة** (يظهر في القائمة).
   - **نوع الحدث** (مثلاً `PurchaseInvoiceApproved`).
   - **الأولوية** (الرقم الأصغر ينفذ أولاً).
3. في حقل JSON، اكتب التعريف:
   ```json
   {
     "conditions": { "all": [] },
     "actions": [
       {
         "type": "PostJournalEntry",
         "narration": "قيد جديد",
         "lines": [
           { "accountCode": "1000", "nature": "debit",  "amountFormula": "500" },
           { "accountCode": "2000", "nature": "credit", "amountFormula": "500" }
         ]
       }
     ]
   }
   ```
4. اضغط **حفظ**.

### 9.5. تشغيل قاعدة من خارج النظام

```bash
curl -X POST http://localhost:5000/api/rules/trigger \
  -H "Authorization: Bearer <token>" \
  -H "X-Company-Id: <company-id>" \
  -H "Content-Type: application/json" \
  -d '{
    "eventName": "PurchaseInvoiceApproved",
    "payload": {
      "invoice": { "number": "INV-001", "total": 1000, "tax": 0 },
      "supplier": { "name": "مورد" }
    }
  }'
```

## 10. ميزان المراجعة

1. اذهب إلى **ميزان المراجعة**.
2. تشاهد كل حساب مع رصيده في عمود **مدين** أو **دائن**.
3. شارة **متوازن ✓** تعني أن إجمالي المدين = إجمالي الدائن.

> 📐 هذه هي معادلة الميزانية A = L + E بصيغتها الأبسط: مجموع المدين يساوي مجموع الدائن.

## 11. قائمة الدخل والميزانية

(متوفرة عبر الـ API حالياً؛ عرضها في الواجهة قيد التطوير.)

- **قائمة الدخل**: `GET /api/reports/income-statement?companyId=...&from=2026-01-01&to=2026-12-31`
- **الميزانية**: `GET /api/reports/balance-sheet?companyId=...&asOf=2026-12-31`

## 12. نصائح سريعة

- ✅ **القيد المتوازن**: مجموع المدين = مجموع الدائن دائماً.
- ✅ **استخدم القوالب**: لا تخترع قواعد من الصفر. انسخ قالب جاهز وعدّل ما يلزم.
- ✅ **اختبر قبل التفعيل**: استخدم زر ▶️ لاختبار أي قاعدة قبل تفعيلها.
- ✅ **تبديل الشركات**: لا تنسَ تبديل الشركة النشطة عند الانتقال بين الشركات.

## 13. حل المشاكل

| المشكلة | الحل |
|---------|-----|
| لا أستطيع الدخول | تأكد من البريد وكلمة المرور. الحسابات التجريبية في الأعلى. |
| لا أرى بعض الشركات | مدير الشركة القابضة يربطك بالشركات. تواصل معه. |
| القيد غير متوازن | راجع المبالغ في كل بند. إجمالي المدين يجب أن يساوي إجمالي الدائن. |
| الحساب غير موجود في القائمة | أضفه من صفحة **شجرة الحسابات** أولاً. |
| القاعدة لم تشتغل | تحقق من نوع الحدث في JSON. يجب أن يطابق اسم الحدث. |
